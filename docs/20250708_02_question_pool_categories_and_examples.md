# 質問プールカテゴリ・質問例リスト（2025/07/08）

## 概要

治療ロードマップの「質問リスト作成」機能で利用する質問プールのカテゴリと、各カテゴリごとの代表的な質問例を体系的にまとめる。

---

## カテゴリ一覧と質問例

### 1. 治療法
- 治療法の選択肢ごとのメリット・デメリットは何ですか？
- それぞれの治療法の成功率やリスクは？
- 標準治療と先進医療の違いは？
- 私の状態に最適な治療法はどれですか？
- 治療法の変更は可能ですか？

### 2. 副作用・生活
- 副作用はどのくらいの頻度で起こりますか？
- どんな副作用が予想されますか？
- 副作用が出た場合の対処法は？
- 日常生活で気をつけることはありますか？
- 食事や運動で制限されることは？
- 治療中に旅行や外出は可能ですか？

### 3. 費用・制度
- 治療費の目安と保険の適用範囲は？
- 高額療養費制度や医療費控除は利用できますか？
- 公的な支援制度や相談窓口はありますか？
- 治療費の支払い方法や分割は可能ですか？

### 4. 家族・サポート
- 家族がサポートできることは何ですか？
- 家族への説明はどうすればよいですか？
- 家族の同席や相談は可能ですか？
- 家族の心理的サポートについて教えてください

### 5. 仕事・社会復帰
- 仕事はいつから再開できますか？
- 休職・復職の手続きや必要書類は？
- 職場への説明や配慮事項は？
- 治療と仕事の両立は可能ですか？

### 6. その他
- 他の患者さんの体験談は聞けますか？
- 治療中に気をつけるべきことは？
- 相談できる窓口やサポート団体は？
- 今後の見通しや再発リスクについて教えてください
