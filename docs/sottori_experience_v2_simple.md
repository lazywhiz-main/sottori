# Sottori 体験設計 v2.0：シンプル×継続強化

*作成日：2025-06-30*  
*設計思想：「一度セルフチェックをしておけば、必要な情報を勝手に収集してよしなに整理してくれる」*

---

## 🎯 **核心体験：5つのステップ**

### **Step 1: 30秒セルフチェック（既存のまま）**
```
✅ 実装済み（高品質）
- チャット形式の5段階質問
- 「わからない」を正当な選択肢として扱う
- 途中保存・再開機能
- 編集・戻る機能
```

### **Step 2: 3分ロードマップ（改良版）**
```
🔧 改良対象
現在：AI生成 + フォールバック
改良後：シンプル×信頼できる情報源

改良ポイント：
- 出典を明確に記載（「日本がん学会ガイドライン」等）
- 「参考情報として」を自然に配置
- 最後に「医師に相談してください」を必ず記載
- 家族向けの「やさしい日本語」版も同時生成
```

### **Step 3: バックグラウンド情報収集（新機能）**
```
💫 新規実装
ユーザーの関心領域に基づいて、システムが自動で：

1. 信頼できる情報源から最新情報を収集
   - 厚生労働省がん情報サービス
   - 主要がん学会のガイドライン
   - 各都道府県のがん拠点病院情報
   - 臨床試験情報（UMIN-CTR）

2. ユーザーの状況に合わせて内容を整理
   - がん種・ステージ・地域・関心事項でフィルタリング
   - 「今、知っておくべき情報」として優先順位付け
   - 家族にも分かりやすい表現に翻訳

3. 準備完了をやさしく通知
   - 「お時間のある時にどうぞ」
   - 「新しい情報が準備できました」
   - 「急がなくて大丈夫です」
```

### **Step 4: やさしい更新通知（新機能）**
```
🔔 新規実装
プレッシャーを与えない継続的な関係性：

頻度：
- 1週間後：「調子はいかがですか？」
- 1ヶ月後：「状況に変化はありましたか？」
- 情報更新時：「新しい情報があります」

メッセージトーン：
- 「お忙しい中、お疲れさまです」
- 「無理をしなくて大丈夫です」
- 「お時間のある時に、ご確認ください」
- 「何も変わっていなくても、大丈夫です」
```

### **Step 5: また来てください（強化）**
```
🔄 継続強化
いつでも情報を更新、状況変化に対応：

新機能：
- 前回の情報を保持して継続表示
- 「変わったこと」だけ聞く短縮チェック
- 治療段階の変化を自動検知して情報更新
- 家族からの質問・気づきを反映
```

### **3. 継続フォロー機能**

#### **状況変化の検知**
```typescript
// src/lib/follow-up/change-detection.ts

interface StatusChange {
  type: 'treatment-stage' | 'concern-area' | 'family-situation' | 'emotional-state'
  oldValue: string
  newValue: string
  significance: 'minor' | 'moderate' | 'major'
  recommendedAction: RecommendedAction
}

// 変化に応じた情報更新
async function handleStatusChange(userId: string, change: StatusChange): Promise<void> {
  if (change.significance === 'major') {
    // 治療段階が変わった場合：新しい情報を収集
    await triggerBackgroundCollection(userId, change.newValue)
    
    // やさしい通知
    await sendGentleNotification(userId, {
      message: '状況が変わられたのですね。新しい段階に合わせて、情報を整理し直しています。少し時間をいただきますが、準備ができましたらお知らせします。',
      tone: 'supportive'
    })
  }
}
```

## 🎨 **最終的なユーザー体験**

```
「Sottoriは、私の状況を覚えていてくれて、
 勝手に必要な情報を集めて整理してくれる。

 でも、急かされることは一切なくて、
 私のペースで、家族と一緒に、
 少しずつ前に進めている。

 何より、『迷ったらまた来て』という
 優しい気持ちが伝わってきて、
 一人じゃないんだなって思える。」
```
