# 📊 Sottori データ収集戦略（改訂版）
**作成日**: 2025年1月3日  
**ステータス**: 承認済み  
**前回からの変更**: 網羅的収集から価値重視・低リスク戦略に転換

## 🎯 **戦略転換の背景**

### **従来の問題点**
- ❌ 網羅的収集の維持コストが高い
- ❌ サイト構造変更でスクレイピング破綻リスク
- ❌ 法的リスク（利用規約確認・遵守コスト）
- ❌ 情報の重複・品質のバラつき
- ❌ ユーザーニーズとのミスマッチ

### **新戦略の方針**
- ✅ **高品質・低頻度収集**: 月1回の確実な価値提供
- ✅ **独自コンテンツ制作**: 咀嚼された実用的情報
- ✅ **AI検索統合**: ChatGPT検索モード相当の機能
- ✅ **法的リスク最小化**: 低リスクサイトに限定

### **3. AI検索機能（ChatGPT検索モード相当）**

#### **🤖 技術仕様**
```typescript
interface AISearchConfig {
  searchMode: 'web_enhanced' | 'knowledge_base' | 'hybrid'
  
  userContext: {
    cancerType: string           // がん種
    stage: string               // ステージ
    treatments: string[]        // 治療履歴
    preferences: UserPreferences // 個人設定
  }
  
  dataRetention: {
    saveQueries: boolean        // クエリ保存
    saveResponses: boolean      // レスポンス保存
    retentionPeriod: string     // 保持期間
    anonymizeData: boolean      // 匿名化
  }
}
```

#### **🔒 プライバシー・データ保存方針**
```typescript
interface SearchLog {
  id: string
  timestamp: Date
  cancerType: string           // 乳がん、肺がん等
  stage?: string              // ステージ情報（オプション）
  queryCategory: string       // 治療、副作用、制度等
  searchSuccess: boolean      // 検索成功フラグ
  responseRelevance: number   // レスポンス関連度（1-5）
  
  // 個人特定情報は一切保存しない
  // ユーザーIDやセッション情報は除外
}
```
