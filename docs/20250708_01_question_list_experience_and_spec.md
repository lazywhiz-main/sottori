# 質問リスト作成機能 体験シナリオ・詳細仕様（2025/07/08）

## 1. どんな心境で「質問リスト作成」ページに入るのか

### ● 典型的なユーザー心理・状況
- 治療方針決定の直前や主治医との面談前
  - 何を聞けばいいのか分からない、大事なことを聞き漏らしたくない
  - 家族や周囲から"これも聞きなさい"とアドバイスされた
  - ネットで調べたが自分の状況に合う質問が分からない
- 不安・緊張・焦り
  - 治療の選択肢が多くて迷っている
  - 医師に遠慮して聞きたいことが聞けないかも
  - 家族のためにも納得して決めたい
- 前向きな気持ちも
  - 自分の治療を自分で理解したい
  - 後悔しない選択をしたい

## 2. この機能とともにどんな行動をしてほしいか

### ● 期待するユーザー行動
1. 自分の疑問や不安を"言語化"する
2. 質問を整理し、優先順位をつける
3. 家族や同席者と共有する
4. 医師との面談でリストを活用する
5. 面談後に振り返り、家族と再共有する

## 3. 機能がどうあるべきか（詳細仕様）

### ● 機能要件
- 質問プール（テンプレート）からのピックアップ＋自由追加
- 優先度設定・並べ替え（「優先」「通常」ラベル、↑↓ボタン等）
- 質問の編集・削除
- 家族・同席者との共有（LINE/メール/QR/印刷等）
- 相談記録・メモ
- 保存・再利用

### ● 質問プール（テンプレート）の仕様

#### 1. カテゴリ分け
- 治療法
- 副作用・生活
- 費用・制度
- 家族・サポート
- 仕事・社会復帰
- その他

#### 2. 質問例（カテゴリ別）
- **治療法**
  - 治療法の選択肢ごとのメリット・デメリットは？
  - それぞれの治療法の成功率・リスクは？
- **副作用・生活**
  - 副作用はどのくらいの頻度で起こりますか？
  - 日常生活で気をつけることは？
- **費用・制度**
  - 治療費の目安と保険の適用範囲は？
  - 公的な支援制度は利用できますか？
- **家族・サポート**
  - 家族がサポートできることは？
  - 家族への説明はどうすれば？
- **仕事・社会復帰**
  - 仕事はいつから再開できますか？
  - 休職・復職の手続きは？
- **その他**
  - 治療中に旅行は可能ですか？
  - 他の患者さんの体験談は聞けますか？

#### 3. ピックアップ基準・並べ方
- ユーザーの治療段階・状況に応じて自動提案
- 過去のユーザー行動・選択履歴も考慮
- ユーザーが「優先」ラベルを付けたものが上位に来る
- 自由追加・並べ替えでカスタマイズ可能

## 4. 体験の理想的な流れ

1. ユーザーは不安や疑問を抱えた状態でページに入る
2. テンプレートから自分に合う質問を選び、自由に追加・編集
3. 優先順位をつけて整理し、家族と共有
4. 医師との面談でリストを活用し、回答や気づきを記録
5. 面談後も振り返りや再相談に活用できる
