# 治療ロードマップ画面設計とユーザーストーリー（改訂版）

## 概要

治療ロードマップの自然な体験の流れを実現するための画面設計とユーザーストーリーを整理し、体験設計との整合性を検証する。既存の構造（dashboardにロードマップ概要、/roadmap-detailがメインページ）を活用した改善案を含む。

## 1. 既存構造の確認と活用

### 1.1 現在の構造
- **Dashboard** (`/dashboard`): ロードマップの概要表示
- **ロードマップ詳細** (`/roadmap-detail`): 治療ロードマップ詳細のメインページ（既存）

### 1.2 既存ページの役割と改善点
- **Dashboard**: 全体像把握、現在地確認、次のステップへの導線
  - **改善**: 初回訪問時の心理的サポート、段階的ガイド機能
- **/roadmap-detail**: 現在のステップの詳細理解とアクション実行
  - **改善**: 動的表示ロジック、感情的サポート、段階的アクション表示

## 2. 必要な画面の洗い出し（改訂版）

### 2.1 既存画面の改善

#### 2.1.1 Dashboard（/dashboard）の強化
**目的**: 全体像把握と初回訪問時の心理的サポート
**改善機能**:
- **初回訪問検知**: 初回訪問時の歓迎メッセージ
- **不安軽減メッセージ**: 安心感を提供するメッセージ
- **段階的ガイド**: 「要点だけ見る」モード
- **現在地の明確化**: 現在のステップをより分かりやすく表示
- **次のステップへの導線**: より自然な遷移

#### 2.1.2 ロードマップ詳細（/roadmap-detail）の改善
**目的**: 現在のステップの詳細理解と動的アクション実行
**改善機能**:
- **動的表示ロジック**: ユーザーの状態に応じた表示制御
- **感情的なサポート**: 不安・迷い・疲労時のメッセージ
- **段階的アクション表示**: プライマリ・セカンダリ・サポート系の優先度
- **「わからない」「後で決める」選択肢**: 判断を急がせない機能
- **コンテキスト検知**: 家族同伴時などの自動検知

### 2.2 新規追加画面（必要最小限）

#### 2.2.1 アクション実行画面
**質問リスト作成** (`/roadmap-detail/action/question-list`)
- 医師相談の効果的な準備
- 質問項目の選択・追加・優先順位設定

**家族共有** (`/roadmap-detail/action/family-share`)
- 家族向け説明資料の生成
- 共有方法の選択と履歴管理

**メモ・記録** (`/roadmap-detail/action/notes`)
- 重要な情報の記録と管理
- カテゴリ別整理と検索機能

#### 2.2.2 サポート画面
**相談窓口** (`/roadmap-detail/support/consultation`)
- 専門家への相談導線
- 相談方法の選択と内容整理

**同じ経験者の声** (`/roadmap-detail/support/peer-support`)
- 共感と実体験からの学び
- 経験談の閲覧とコミュニティ参加

#### 2.2.3 ステップ別詳細画面（オプション）
**診断詳細** (`/roadmap-detail/step/diagnosis`)
- 検査結果の詳細説明
- 用語解説と図解

**治療方針決定詳細** (`/roadmap-detail/step/treatment-decision`)
- 治療選択肢の比較表
- メリット・デメリット分析

**治療開始詳細** (`/roadmap-detail/step/treatment-start`)
- 治療スケジュール表示
- 副作用情報と生活調整ガイド

## 3. ユーザーストーリー（改訂版）

### 3.1 Dashboard改善のユーザーストーリー

#### ストーリー1: 初回訪問者の不安軽減
**As a** 初めてSottoriを使う患者  
**I want to** 安心して治療の流れを理解したい  
**So that** 不安を軽減して次のステップに進める

**Acceptance Criteria**:
- 初回訪問時に歓迎メッセージが表示される
- 不安を和らげるメッセージが含まれる
- 全体の流れが分かりやすく表示される
- 現在の状況が明確に示される

#### ストーリー2: 情報過多への対応
**As a** 情報が多すぎて疲れている患者  
**I want to** 要点だけを素早く理解したい  
**So that** 必要な情報だけを得られる

**Acceptance Criteria**:
- 「要点だけ見る」モードが提供される
- 重要な情報が優先表示される
- 詳細は後で読めるようになっている
- 段階的な情報開示が可能

### 3.2 /roadmap-detail改善のユーザーストーリー

#### ストーリー3: 動的なサポート
**As a** 現在のステップで迷っている患者  
**I want to** 自分の状況に合ったサポートを受けたい  
**So that** 適切な判断ができる

**Acceptance Criteria**:
- ユーザーの状態に応じたメッセージが表示される
- 不安・迷い・疲労時に適切なサポートが提供される
- アクションが段階的に表示される
- 「わからない」「後で決める」選択肢が利用できる

#### ストーリー4: 家族同伴時の対応
**As a** 家族と一緒に情報を確認したい患者  
**I want to** 家族向けの情報が優先表示される  
**So that** 家族と一緒に理解できる

**Acceptance Criteria**:
- 家族同伴時を検知する機能がある
- 家族向けの説明が優先表示される
- 共有機能が強調される
- 家族との話し合いのサポートが提供される

### 3.3 アクション実行画面のユーザーストーリー

#### ストーリー5: 医師相談の準備
**As a** 医師に相談したい患者

**Acceptance Criteria**:

#### ストーリー6: 家族との共有
**As a** 家族に情報を共有したい患者  
**I want to** 家族向けの説明資料を作成したい  
**So that** 家族が理解しやすい形で共有できる

**Acceptance Criteria**:
- 家族向けの説明資料が自動生成される
- 共有方法の選択が可能
